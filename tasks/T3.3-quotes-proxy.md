# T3.3 — `/quotes` proxy

Size: M · Prereqs: T3.2 · Files: `server/providers_brapi.py`, `server/server.py`

## Subtask 0 — resolve an open question first

**The brapi FX and crypto endpoints are unconfirmed.** Before writing anything, check
<https://brapi.dev/docs> and establish:

- the crypto quote endpoint and its response shape
- whether FX (USD/BRL, EUR/BRL) is served, and how
- which tickers work without a token (PETR4, MGLU3, VALE3, ITUB4 are the documented free
  sample set) and which require one

If brapi does not cover FX or crypto cleanly, use these instead — both are key-free:

- crypto: Binance public API
- FX: AwesomeAPI (`economia.awesomeapi.com.br`)

Record whatever you find at the top of `providers_brapi.py`, and update
`tasks/STATUS.md`'s open-questions section.

## Steps

1. `providers_brapi.py` with the outbound call isolated in one small function, so
   `unittest.mock` can patch exactly that one thing.
2. A **pure** `normalise(raw) -> list[dict]` producing the contract shape from T1.2:
   `{symbol, price, changePct}`. This is where the tests aim.

   `fx` needs its own normaliser, and it is the one place the two spellings meet: config says
   `USD-BRL`, the payload says `{pair: "USD/BRL", rate, changePct}`. Nothing downstream should
   ever see a hyphen.
3. `GET /quotes` returns `{quotes: [...], fx: [...], crypto: [...]}`.
4. Cache responses for `quotes_interval_s`. The free tier is 15k requests/month — a 2s poll
   would burn that in days.
5. On upstream failure, serve the last good value with a `stale: true` flag rather than an
   error. The panel showing a slightly old price beats the panel showing nothing.

## Acceptance

```bash
curl -sf http://localhost:8777/quotes | python -m json.tool
```

Contains every configured symbol, with values matching the upstream source. And:

```bash
python -m unittest discover -s server/tests -t .
```

with **no network access** — the unit tests patch the outbound call.

## Notes

- The token never leaves this process.
- Log upstream failures with enough detail to diagnose, but never log the token.
