# T6.16 — Relative humidity on the weather card

Size: S · Prereqs: T6.15 · Files: `server/providers_openmeteo.py`, `web/js/format.js`,
`web/themes/*/theme.{js,css}`, `web/js/mock.js`

Requires: nothing beyond a checkout, and the phone for the manual check

## Goal

Asked for on 2026-09-30: the air's relative humidity under the day's low and high, with a
humidity icon, if the API has it. Open-Meteo does: `current=relative_humidity_2m`, a whole
percent. Checked against the live API the same day, which answered 40.

## Steps

1. Ask for `relative_humidity_2m` in `fetch_forecast`, and normalise it to `humidity`, an int or
   None.
2. `relativeHumidity(weather)` in `format.js`: 0..100 or null, never a dash.
3. neon: a drop and the number on a line under the range. plain: "Umidade relativa: 40%".

grep -q 'relative_humidity_2m' server/providers_openmeteo.py
