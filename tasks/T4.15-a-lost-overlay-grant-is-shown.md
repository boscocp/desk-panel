# T4.15 — A lost overlay grant is logged when it goes, and shown on the panel

Size: S · Prereqs: T4.10, T4.12 · Files:
`android/app/src/main/java/dev/bosco/deskpanel/OverlayGrant.java`,
`android/app/src/main/java/dev/bosco/deskpanel/PanelService.java`,
`android/app/src/main/java/dev/bosco/deskpanel/DataPayload.java`,
`android/app/src/main/java/dev/bosco/deskpanel/Markers.java`,
`web/js/format.js`, `web/themes/neon/theme.js`, `web/themes/neon/theme.css`,
`web/themes/plain/theme.js`,
`docs/adr/0026-a-lost-overlay-grant-is-shown.md`

Requires: the phone on adb

## Goal

Found on 2026-11-17. The screen stayed dark from 2026-11-16 16:19 until a hand pressed the
power key at 10:01 the next day, through two logins at the PC and one at the Mac. A WebView
update had killed the app at 15:49. The watchdog revived the service at 16:19, and "Display
over other apps" was `ignore`, so the revived service could not raise the panel. The grant had
been in use on 11-06, and nothing recorded when it went. This is the fifth time it has gone.

## Steps

1. `OverlayGrant.change(before, now)`, plain Java: `LOST` on the first reading that finds the
   grant missing (a service's first reading included), `BACK` on its return, `NONE` otherwise.
2. `PanelService` reads `Settings.canDrawOverlays` on start, on every battery broadcast, and
   500 ms after an `AppOpsManager` change to `OPSTR_SYSTEM_ALERT_WINDOW`. It logs
   `overlay=lost` or `overlay=back` on a change.
3. `DataPayload.withOverlay` folds `"overlay": false` into the battery object when the grant
   is missing, and adds nothing when it is held.
4. `batteryFields` reports `overlayOff`, and `formatBattery` appends the word. The neon theme
   draws it as a red note, and the plain theme turns the line red through `batteryLineClass`.
   `DataPayload.fold` is what `publish` calls, so "no reading yet is not a loss" is on the JVM.
5. [ADR 0026](../docs/adr/0026-a-lost-overlay-grant-is-shown.md), the markers in
   `docs/TESTING.md`, and the symptom in `docs/INSTALL-PHONE.md`.

```bash
grep -q 'overlayOff' web/themes/neon/theme.js
test -f docs/adr/0026-a-lost-overlay-grant-is-shown.md
python scripts/check_acceptance.py
```

On the phone, with this build installed, which resets the grant to `ignore`. An install does
not restart the app (ADR 0025), so start it first:

```bash
adb shell am start -n dev.bosco.deskpanel/.MainActivity
adb shell sleep 3
adb logcat -d -s DeskPanel | grep -q 'overlay=lost'
adb logcat -c
adb shell appops set dev.bosco.deskpanel SYSTEM_ALERT_WINDOW allow
adb shell sleep 2   # the service reads the grant 500 ms after the change
adb logcat -d -s DeskPanel | grep -q 'overlay=back'
```
