# T2.4 — MIUI smoke test: autostart, battery, reboot survival

Size: M · Prereqs: T2.2 · Files: `docs/INSTALL-PHONE.md` (no code)

Requires: phone (on adb), and a reboot of it

## Goal

Find out **now** whether MIUI will let this app run permanently. This is the least predictable
risk in the project, which is why it sits here instead of at the end. Discovering it during
packaging would be expensive.

## Steps

1. Settings → Apps → Manage apps → desk-panel:
   - **Autostart: on**
   - **Battery saver: No restrictions**
2. App switcher: pull the app card down to lock it in recents.
3. Developer options: **Stay awake** while charging.
4. Reboot the phone. Do not touch it afterwards.
5. Leave it running for several hours and check it is still updating.

## Acceptance

After a reboot, with no interaction:

```bash
adb shell dumpsys activity activities | grep -i mResumedActivity   # names desk-panel
```

within about two minutes. And after several hours idle, the clock is still advancing.

## Notes

- If MIUI keeps killing it, the escalation path, in order: lock in recents, disable MIUI
  memory optimisation, and as a last resort register the app as a HOME launcher so the system
  treats it as the foreground shell.
- Record whatever you find in `docs/INSTALL-PHONE.md`. The next person — probably you, months
  from now — will not remember which toggle mattered.
