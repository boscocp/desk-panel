# T10.3 — `lint-selftests` globs one directory and the repository has two

Size: XS · Prereqs: none · Files: `Makefile`, `.github/workflows/lint.yml`

Requires: none

## Goal

`server/verify_login_scope.py` carries a `--self-test` with **97 cases** covering the autostart
parsers for Windows, Linux and macOS from fixtures — which is the only way macOS is checkable at
all from this desk (TT.10). `make lint-selftests` discovers self-tests with
`grep -l '"--self-test"' scripts/*.py`, and that glob stops at `scripts/`, so no target ever runs
that command.

**Scope this honestly: the 97 cases are already covered.** `server/tests/test_login_scope.py`
imports `vls.self_test_cases()` and asserts every triple as a subTest, and `make check`'s
`test-server` runs it — break a fixture and the suite goes red today. The first draft of this
task claimed the cases were orphaned; they are not, and [the design
review](../docs/DESIGN-REVIEW.md) carries the correction.

What is unguarded is the **CLI entry point**: argument parsing, the `97/97` summary line and the
exit code are what `docs/SERVER-SETUP.md` tells a person to run on their own machine, and nothing
exercises them. A refactor that broke `--self-test` while leaving `self_test_cases()` correct
would ship green. That is a smaller defect than the one first written down, and still a real one.

## Steps

1. Widen the discovery to the directories whose self-tests are **safe in `make check`** —
   `scripts/` and `server/` — still **by glob and never by a list of file names**, which is the
   rule `lint-selftests` already states, applied one directory wider.
2. Keep it fast enough that `make check` is still the command people run: 97 parser cases over
   fixtures cost milliseconds.
3. The workflow needs no new line — `lint.yml` already runs `make lint-selftests`, which is the
   point of it being a target rather than a list of scripts.

## Acceptance

```bash
make lint-selftests 2>&1 | grep -q 'verify_login_scope'
make lint-selftests
python scripts/check_ci_hygiene.py
make check
```

The first line is the task. The second is that it passes, and the third is that widening the glob
did not leave a guard that `make check` reaches and no workflow runs.

## Notes

- Resist listing *file names*; directories are a different matter. **`e2e/` must stay out of the
  glob**: `e2e/layout/`'s checks drive Firefox over Marionette and exit 2 without a browser, and
  keeping them outside `make check` is deliberate and documented. A glob that reached `e2e/`
  would make `make check` need a browser the day somebody adds a `--self-test` there. Widen it
  again when a fourth directory grows one, and say in the recipe's comment why `e2e/` is not in
  the list.
- `python` and not `python3` in whatever the recipe becomes, matching the Makefile's other rules.
