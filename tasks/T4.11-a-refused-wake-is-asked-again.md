# T4.11 — A refused wake is asked for again

Size: S · Prereqs: T4.4, T4.10 · Files:
`android/app/src/main/java/dev/bosco/deskpanel/WakeRetry.java`,
`android/app/src/main/java/dev/bosco/deskpanel/PanelService.java`,
`android/app/src/main/java/dev/bosco/deskpanel/MainActivity.java`,
`android/app/src/main/java/dev/bosco/deskpanel/Markers.java`,
`docs/adr/0024-a-refused-wake-is-asked-again.md`

Requires: the phone on adb

## Goal

Found on 2026-10-23. The monitor and the phone slept at 12:25 for inactivity. At 13:35:23 the
PC answered again and the app logged `state=online` and `screen=wake`. Android then dropped the
`startActivity` (`Background activity start [... inVisibleTask: false]`), so the screen stayed
dozing with every ping `ok`. "Display over other apps" had been switched off on the phone with
no reinstall, and nothing in the app asked again or said why.

## Steps

1. `WakeRetry.next(online, interactive)`, plain Java: `STOP`, `SETTLED` (display on) or
   `RETRY` (display dark). `WakeRetry.showing(focused, interactive)` for the panel being up.
2. `PanelService.bringPanelToFront` books a check `WakeRetry.RETRY_MS` (30 s) later, unless the
   panel is already showing. `RETRY` logs `wake=retry` and asks again. `SETTLED` releases the
   offline wake lock. Focus on a lit display, or the PC going away, removes the check.
3. `MainActivity.onWindowFocusChanged` reports focus both ways to `PanelService.panelFocus`.
4. Every wake request logs `overlay=denied` when `Settings.canDrawOverlays` is false.
5. [ADR 0024](../docs/adr/0024-a-refused-wake-is-asked-again.md), the two markers in
   `docs/TESTING.md`, and the symptom in the README's troubleshooting.

## Acceptance

```bash
docker compose -f docker/compose.yml run --rm build ./gradlew test
grep -q 'WakeRetry.RETRY_MS' android/app/src/main/java/dev/bosco/deskpanel/PanelService.java
grep -q 'PanelService.panelFocus(hasFocus)' android/app/src/main/java/dev/bosco/deskpanel/MainActivity.java
test -f docs/adr/0024-a-refused-wake-is-asked-again.md
python scripts/check_acceptance.py
```

On the phone, with this build installed, the PC up and "Display over other apps" denied:

```bash
adb shell appops set dev.bosco.deskpanel SYSTEM_ALERT_WINDOW ignore
adb logcat -c && adb shell am force-stop com.google.android.webview
# after the watchdog revives the service (up to ~26 min):
adb logcat -d | grep -q 'overlay=denied'
adb logcat -d | grep -q 'wake=retry'
adb shell appops set dev.bosco.deskpanel SYSTEM_ALERT_WINDOW allow
```
