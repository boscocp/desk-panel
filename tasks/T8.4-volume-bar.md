# T8.4 — A volume bar beside MIC

Size: M · Prereqs: T8.2, T8.3 · Files: `server/actions.py`, `server/server.py`,
`android/.../{Actions,DataPoller,DataPayload,PanelService,MainActivity}.java`, `web/js/*.js`,
`web/themes/*/theme.{js,css}`, `docs/adr/0015-the-panel-can-act-on-the-pc.md`

Requires: the phone on adb and each PC, for the manual check

## Goal

Asked for on 2026-09-30: a bar beside the MIC button that controls the PC's overall volume, on
Windows, macOS and CachyOS. The owner chose the real slider, and so the ADR 0015 amendment
(*One action carries a value, and only this one*).

## Steps

1. `actions.py`:
   - `volume` joins the catalogue.
   - `parse_level` turns the path's text into an int from 0 to 100.
   - `volume_commands` holds `wpctl` then `pactl`, `osascript`, and PowerShell with
     IAudioEndpointVolume slots 4 and 6.
   - `level_from` reads back the level every mixer reports.
2. `POST /action/volume/<level>` goes through `run_action`'s checks in the same order. The TLS
   key check covers every `/action/...` path.
3. `/quotes` carries `volume: {level}`, read off the request path and cached for 20 s, or
   `null` when the bar is off.
4. The phone:
   - `setVolume(int)` on the bridge;
   - `Actions.volumeUrlFor`;
   - `DataPayload` carries `volume`, and the result state is rebuilt from an int.
5. neon draws a segmented bar, twice a button's height, with a speaker on top. plain uses the
   browser's range input. Each sends once, when the finger lifts.
