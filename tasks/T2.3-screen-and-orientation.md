# T2.3 — Keep screen on, landscape, immersive

Size: S · Prereqs: T2.2 · Files: `MainActivity.java`, `AndroidManifest.xml`

## Goal

The panel looks like a panel: landscape, no system bars, screen not sleeping.

## Steps

1. `android:screenOrientation="landscape"` on the activity in the manifest.
2. `getWindow().addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)` — the officially
   recommended approach; screen wake locks have been deprecated since API 17.
3. Immersive full-screen via `WindowInsetsControllerCompat`: hide system bars, set the
   behaviour so a swipe reveals them transiently.
4. Keep the flag in a method that can clear it — T4.4 needs to remove it to let the screen
   sleep. Do not scatter `addFlags` calls around.

## Acceptance

Install and observe: landscape, no status or navigation bar, and the screen still on after ten
minutes untouched.

```bash
adb shell dumpsys window | grep -i "mCurrentFocus"   # names this activity
```

## Notes

- `FLAG_KEEP_SCREEN_ON` stops the screen sleeping. It does **not** stop MIUI's battery manager
  from freezing the process — that is T2.4, and it is a separate problem.
