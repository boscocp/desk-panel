## Goal

Asked for on 2026-09-30: "nesse espaço em cima dos botões ... uma animação em relação ao som
tocado ... as barras verticais de som ... que seja real ao som tocando atualmente", as in
Winamp. The owner chose macOS first, saw it on the panel ("ficou mt bom!"), and asked for
Windows and CachyOS in the same wave. [ADR 0021](../docs/adr/0021-the-spectrum-is-a-stream.md)
is the decision.

## Steps

1. A source per platform writes mono int16 PCM to stdout:
   - macOS: a Swift helper on a Core Audio process tap, `rate=<hz>` first, exiting on stdin EOF;
   - Windows: a C# 5 helper on WASAPI loopback, the same protocol, compiled by
     `install_task.ps1` with Windows' own `csc.exe` and started with `CREATE_NO_WINDOW`;
   - Linux: `parec --device=@DEFAULT_MONITOR@` at a fixed 24 kHz, with no header.
2. `spectrum.py`: a pure FFT with sixteen log-spaced bands (50 Hz–11 kHz) in dBFS mapped to
   0..255, plus a hub that runs one source for any number of streams and stops it 5 s after the
   last one ends.
3. `GET /spectrum` streams one hex line per frame. It is a data route (key in private mode),
   404 when `spectrum` is off or the platform cannot capture.
4. The phone runs `SpectrumStream` while `ONLINE`, validates each line with `SpectrumFrame`,
   coalesces frames onto the main thread and calls `window.onSpectrum`.
5. The page runs each frame through the `spectrumStep` physics (a jump up, a fixed-rate fall,
   and peak caps that hold, then drop). The neon theme draws segmented columns on a canvas over
   the buttons.

## Manual check

- **macOS, done 2026-09-30.** With `"spectrum": true` on the Mac and music playing, the Redmi
  logged `spectrum=open`, the server served `GET /spectrum` 200, and `spectrum-tap` ran as the
  server's child. macOS prompted for System Audio Recording for `python3`, and the frames
  carried real levels.
- **Linux, in a container:** a real PulseAudio with a null sink, a 1 kHz tone played into it,
  and the `parec` source read through the hub. See the wave note for the numbers.
- **Not yet:** the Windows helper on the Windows PC. Run `install_task.ps1`, set
  `spectrum = true`, play something, and look for moving bars and no console window.
  Also CachyOS against PipeWire: set `spectrum = true` and restart the user unit.
