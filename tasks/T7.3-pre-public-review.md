# T7.3 — Pre-public review

Size: M · Prereqs: none (runs last by convention, not by dependency) · Files: `README.md`, and whatever the audit turns up

## Goal

Make the repository safe and presentable before flipping it from private to public. It is meant
to be a portfolio piece, so both halves of that matter.

## Steps

1. **Secret audit — the part that cannot be undone later:**

   ```bash
   git log -p | grep -iE "token|password|keystore|api[_-]?key|secret"
   git log --all --name-only --pretty=format: | sort -u | grep -iE "config\.json|keystore|\.jks|\.env"
   ```

   Anything real found here needs history rewriting **and** rotating the credential. A later
   commit that deletes a file does not remove it from history.

2. **The token specifically.** Confirm `server/config.json` was never committed and the brapi
   token appears nowhere — including in a fixture, a test, a doc example or a screenshot.

3. **README.** It is the first thing a reader sees. Check it explains what the project is, why
   it exists, and the interesting decisions — and that every link resolves.

4. **Screenshots.** A photo of the panel on the actual phone in its stand. Crop out anything
   identifying: the LAN IP, personal tickers, your city if you would rather not share it.

5. **Placeholders.** Replace the pinned LAN IP in committed examples with `192.168.1.100` or
   similar, so nobody publishes their own network layout.

6. **The ADRs.** Read them once as an outsider. They are the strongest thing in this repo —
   they show options weighed and rejected with evidence. Confirm they still match what was
   built, especially ADR 0005, which T4.4 may have changed.

7. Add a LICENSE file if one is not there yet.

## Acceptance

```bash
! git grep -nE '\b192\.168\.[0-9]{1,3}\.[0-9]{1,3}\b' -- . ':!docs' ':!*.md' | grep -qv '192\.168\.1\.100'
python scripts/check_acceptance.py
python scripts/check_links.py
```

Two changes from the original. The first line was `... | grep -v ...` with the verdict "returns
nothing" — which exits 1 when it passes. The second is new: the real LAN IP is pinned in
committed source (`network_security_config.xml`, the poller), and the secret sweep above does
not look for an address. `192.168.1.100` is the agreed placeholder.

## Manual check

The repo reads well to someone who has never seen it.
