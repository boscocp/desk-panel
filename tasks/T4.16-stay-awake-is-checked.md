# T4.16 — "Stay awake" is checked, not described

Size: XS · Prereqs: T4.4 · Files:
`scripts/check_phone_settings.py`, `Makefile`, `docs/INSTALL-PHONE.md`

Requires: the phone on adb

## Goal

Reported from the chair on 2026-11-26: the PC's monitor went to sleep and the phone did not.
It dimmed and sat on the lock screen. The app had done everything: `state=idle` and
`screen=sleep` at 17:00:56, `FLAG_KEEP_SCREEN_ON` released, `showWhenLocked` off. But
`dumpsys power` read `mStayOn=true` and `stay_on_while_plugged_in=7`, so Developer options →
"Stay awake" was on, for all three power sources, on a phone that is always charging. ADR 0005
and INSTALL-PHONE said it must be off, and nothing checked. Nothing in the repository sets it.
`7` is what `scrcpy --stay-awake` sets.

## Steps

1. `scripts/check_phone_settings.py` reads the setting over adb. It exits 1 with the fix
   command if a setting does not hold, and 2 when adb cannot read it, with adb's own error. It has a `--self-test`.
2. `make phone-settings` runs it, and `install-phone` and `e2e` depend on it.
3. INSTALL-PHONE step 5 points at the target.

## Acceptance

```bash
python scripts/check_phone_settings.py --self-test
grep -q '^install-phone: phone-settings' Makefile
grep -q '^e2e: phone-settings' Makefile
python scripts/check_acceptance.py
```

On the phone:

```bash
make phone-settings
adb shell settings put global stay_on_while_plugged_in 7
python scripts/check_phone_settings.py; test $? -eq 1
adb shell settings put global stay_on_while_plugged_in 0
make phone-settings
```
