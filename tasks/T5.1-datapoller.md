# T5.1 — `DataPoller`, replacing the mock

Size: M · Prereqs: T4.3, T3.3, T3.4 · Files: `DataPoller.java`, `MainActivity.java`,
`web/js/app.js`

## Goal

Real quotes and weather on the panel, arriving through the same `window.onData()` entry point
the mock already uses.

## Steps

1. `DataPoller.java` — fetch `/quotes` and `/weather` from the PC on their own intervals, well
   apart from the 2s ping. The server caches, so polling faster gains nothing.
2. Merge both into the single payload shape defined in T1.2 and push it in one call:
   `webView.evaluateJavascript("window.onData(" + json + ")", null)`.
3. `web/js/app.js` renders the real payload. It should need **no changes** if the shape matches
   the mock — if it does need changes, the contract drifted and the mock should be fixed too.
4. Only poll while online. Offline, `PcPoller` is the only thing running.
5. Escape the JSON properly before interpolating into `evaluateJavascript`. A stray quote in a
   symbol name should not be able to break the call.

## Acceptance

```bash
curl -sf http://<pc-ip>:8777/quotes
```

and the values on the phone match. Weather likewise.

```bash
docker compose -f docker/compose.yml run --rm build ./gradlew test
```
