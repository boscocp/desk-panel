# T4.5 — The panel follows more than one PC

Size: M · Prereqs: T4.2, T2.5, T3.10 · Files: `android/app/src/main/java/dev/bosco/deskpanel/PcHosts.java`,
`PcPoller.java`, `DataPoller.java`, `PanelService.java`, `android/app/build.gradle.kts`,
`docs/adr/0016-more-than-one-pc.md`

Requires: the phone on adb, and both PCs on the LAN with static reservations, for the behaviour block

## Goal

The desk has a Windows PC and a Mac. The panel should be lit while a human is logged in at
**either**, and should sleep only when both are away. [ADR 0016](../docs/adr/0016-more-than-one-pc.md)
records the decision; this task carries it.

## Steps

1. `PC_IP` in `.env` takes a comma-separated list. Each entry is range-checked, and one address
   behaves exactly as before.
2. The generated `network_security_config.xml` has one `<domain>` per address, and nothing wider.
3. `PcHosts`: the list, the host that answered last, and the probe order (that host first).
   Plain Java, JVM-tested.
4. `PcPoller` asks in that order and stops at the first 200. `DataPoller` and the action presses
   use the host that answered last, read once per data cycle.

Behaviour, with `PC_IP=<windows>,<mac>` built and installed:

```bash
adb logcat -c && adb shell am force-stop dev.bosco.deskpanel && adb shell am start -n dev.bosco.deskpanel/.MainActivity
sleep 15 && adb logcat -d -s DeskPanel | grep -q 'state=online'
# log out of the PC the panel is on; the other stays logged in
sleep 20 && adb logcat -d -s DeskPanel | grep -q 'pc answered at'
! adb logcat -d -s DeskPanel | grep -q 'state=offline'
```
