## Goal

Asked for on 2026-09-30, during the first Windows run of T8.4 and T8.5: the volume bar took up to
three minutes to follow the MCHOSE knob ("o volume do machose demorar mt pra refletir no
telefone"). The level arrived only on `/quotes`, once a minute, behind a 120 s cache that was
there because every Windows read is a PowerShell process. The owner chose the recommended fix:
send the level down the spectrum stream, which is already open twenty times a second while the
panel is lit.

## Steps

1. The Windows helper reads `IAudioEndpointVolume::GetMasterVolumeLevelScalar` on the device it
   captures, at most every 100 ms, and writes `v=<0..100>\n` to **stderr** on start and on each
   change. stdout stays PCM.
2. `HelperSource` pipes stderr and drains it on a thread: `v=` lines go to the hub, any other
   line to the log, which under `pythonw` nothing else would ever see.
3. The hub keeps the last level. Every stream gets `v=<level>` on opening and on each change.
   `on_volume` tells the App, so `/quotes` says the same number. With the `volume` action off,
   `on_volume` is None and no volume line is ever written.
4. A set from the phone goes through the hub too, so every stream hears it.
5. `SpectrumFrame.parseVolume` accepts exactly `v=` and 0..100. `SpectrumStream` coalesces it
   onto the main thread, and `MainActivity` calls `window.onVolume(<int>)`.
6. `app.js` checks it again (`parseVolume`), keeps it in the held payload (`withVolume`), and
   hands it to the theme's optional `volume(level)`. The neon bar's `show` already leaves a
   drag or a set in flight alone.

An APK from before this wave drops the new line: `SpectrumStream` only ever took 32-hex frames.

## Manual check

- **Windows, server side, done 2026-09-30.** The new helper compiled with `csc.exe` and ran
  under the Scheduled Task. A client read `/spectrum` for 90 s while the owner moved the MCHOSE
  V9 PRO slider: 45 `v=` lines, sub-second, e.g. `100 → 81 → 77 → 63 → 47` within one second.
- **Not yet:** the bar on the phone. That needs this wave's APK, built in Docker, which this
  Windows PC does not have.
- **Not covered:** macOS and Linux still take the level from `/quotes`. Their sources report no
  volume: the Swift helper would need the same read, and `parec` has none.
