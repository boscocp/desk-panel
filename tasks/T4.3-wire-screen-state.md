# T4.3 — Wire state to the panel and the screen  🏁 Milestone B

Size: M · Prereqs: T4.2, T2.2 · Files: `MainActivity.java`, `web/js/app.js`

## Goal

The product's actual behaviour: PC off, screen dark; PC on, panel back.

## Steps

1. On every transition, call into the page:

   ```java
   webView.evaluateJavascript("window.onPcState(" + online + ")", null);
   ```

2. `web/js/app.js` — on `false`, render pure black `#000000` and hide everything; on `true`,
   restore. On AMOLED, black pixels are off pixels.
3. Native brightness, on the UI thread:

   ```java
   WindowManager.LayoutParams lp = getWindow().getAttributes();
   lp.screenBrightness = online ? -1f : 0f;   // -1 = system default, 0 = minimum
   getWindow().setAttributes(lp);
   ```

   Window-scoped, so no permission is required and the system brightness is untouched.
4. Log `screen=sleep` / `screen=wake` on each change — the E2E suite depends on these markers
   (TT.6, [ADR 0009](../docs/adr/0009-testing-strategy.md)).

## Acceptance

With the phone installed and the server running: log off Windows, and within a few seconds the
phone goes dark. Log back in, and the panel returns without touching the phone.

**Verify in a dark room.** `screenBrightness = 0f` is the minimum controllable brightness, not
off, and some MIUI builds clamp it higher than asked. If it is visibly glowing, note it here —
T4.4 is the proper fix and this is the evidence that decides it.

## Notes

- This is the milestone worth reaching before quotes and weather. It is the riskiest part and
  the most satisfying to see working.
- If black is not black enough, the interim workaround is an opaque black `View` over
  everything. T4.4 supersedes both approaches if MIUI cooperates.
