# T4.7 — A busy PC is not a logout

Size: S · Prereqs: T3.8, T4.2 · Files: `server/install_task.ps1`, `server/verify_login_scope.py`,
`server/tests/test_login_scope.py`, `server/fixtures/login_scope/windows_schtasks_good.xml`,
`server/fixtures/login_scope/windows_schtasks_real_capture_priority.xml`,
`android/app/src/main/java/dev/bosco/deskpanel/PcState.java`, `PcStateTest.java`,
`docs/adr/0010-login-signal-is-session-scoped.md`, `docs/adr/0005-real-screen-sleep.md`

Requires: the Windows PC with the Scheduled Task installed, for the manual check

## Goal

Reported from the chair on 2026-10-01: "quando iniciei o jogo battlefield a tela do celular
começou a piscar, como se tivesse abrindo e fechando o app". The panel slept and woke while a
game loaded on the PC.

The server log said why. The `/ping` cadence of 2 s broke into gaps of 4–8 s, and after each
gap came `/ping`, `/spectrum`, `/quotes` and `/weather` together: the panel reloading after an
offline-to-online edge, six times in ninety seconds. Not `IDLE`, which keeps the 2 s cadence.
The server process ran at base priority 6, BELOW_NORMAL: `New-ScheduledTaskSettingsSet` was
never given `-Priority`, and the Task Scheduler's default is 7. A game loading at NORMAL then
starved it past `PcPoller.TIMEOUT_MS`.

Setting the running process to Normal by hand stopped the blinking. That is the measurement
this task rests on.

## Steps

1. `install_task.ps1` registers the task with `-Priority 4` (NORMAL), and `Assert-TaskShape`
   reads it back.
2. `verify_login_scope.py` gains `windows.task.priority`: 4–6 pass; absent (the default 7),
   anything below normal and anything above it fail; non-numeric is unknown. The handwritten
   good fixture carried `<Priority>7</Priority>` and is corrected to 4.
3. The old real capture keeps passing everything except the priority, which is the evidence. A
   new capture, taken from the same box after the reinstall, passes every check.
4. `PcState.ONLINE_GRACE_FAILURES = 1`: from ONLINE, the first failed probe is held as ONLINE,
   still counted, so the retry is at the backoff. The second in a row goes OFFLINE. From
   UNKNOWN and from IDLE the first failure is still OFFLINE.

## Acceptance

```bash
python -m unittest server.tests.test_login_scope
python server/verify_login_scope.py --self-test
python -m unittest discover -s server/tests -t .
docker compose -f docker/compose.yml run --rm build ./gradlew test
grep -q -- '-Priority 4' server/install_task.ps1
grep -q 'ONLINE_GRACE_FAILURES = 1' android/app/src/main/java/dev/bosco/deskpanel/PcState.java
```
