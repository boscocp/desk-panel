# T0.5 — Spec remediation

Size: L · Prereqs: none · Files: `tasks/*.md`, `scripts/check_acceptance.py`, `Makefile`,
`CLAUDE.md`, `docs/`

Requires: none

## Goal

Make the backlog executable. Before this task, nothing in it was — not by an agent, not by a
person. The repository stated a rule three times ("every acceptance criterion is a command with
an exit code") and 8 of 36 task files followed it.

## Why this exists as a task at all

The same reason as any other: it changes the repo, so it gets a file and a row. It was found by
auditing the proposal before starting execution, which is also when `docs/LOCAL-MODELS.md` said
the exit-code rule "stops being good hygiene and becomes load-bearing" — because the local
model reports work it did not do. The two tasks that document names as best suited to the local
model, T1.1 and T1.2, were among those whose real check was prose.

## Steps

1. **Acceptance blocks.** Four classes, all fixed:
   - inverted exit code — `grep ... # no output` passes with exit 1 (T7.1, T7.3, TT.1, TT.5)
   - non-terminating — `adb logcat -s`, a bare server start (seven blocks)
   - always zero — `curl -s -w "%{http_code}"` prints and exits 0 (T3.6, T3.7)
   - prose only — no command at all (T4.1, T4.3, T6.3, TT.9)
2. **`scripts/check_acceptance.py`**, wired into `make check` as `make lint-tasks`, so the four
   classes cannot come back.
3. **`Requires:`** in every header that needs hardware; **`## Manual check`** for the
   irreducibly human criteria, which stop pretending to be commands.
4. **The dependency graph**: the T4.1/T4.2 cycle, T4.1's missing T3.5, the seven test tasks
   that declared no prerequisites, TT.2 owning the two `__init__.py` files without which
   `make check` fails.
5. **The payload contract**: `stale`, `night`, one battery bridge, the `USD-BRL` / `USD/BRL`
   split with an owner, `timezone` as config.
6. **Ordering**: T7.1 before T2.4, `out/` at the root.
7. **Cross-platform server**: ADR 0010, T3.5 rewritten, T3.8-T3.11 and TT.10 created.
8. **The cosmetic layer**: one source for the E2E scenario table, the test-layer count, ADR
   0007's Node accounting, the README's present tense, ADR 0005's status.

## Acceptance

```bash
make lint-tasks
python -c "import pathlib,re,sys; f=[p for p in pathlib.Path('tasks').glob('*.md') if re.match(r'^(T\d+\.\d+|TT\.\d+)-',p.name)]; sys.exit(0 if all(re.search(r'^Requires:',p.read_text(),re.M) for p in f) else 1)"
python scripts/check_status.py
```

`check_status.py` asserts the index and the files agree: every task file has a row, every row
with an id has a file or is listed as bootstrap, and no task declares a prerequisite that does
not exist.
