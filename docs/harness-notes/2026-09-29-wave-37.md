# Wave 37 — the pre-public review, up to the photo

T7.3 is the last read before the repository goes public. The sweeps that can be automated were
already green; what was left was reading, and reading found what the sweeps cannot.

## What ran

**T7.3**, on `wave/37-pre-public-review`. The wave was paused mid-way to save context, resumed at
the owner's word, and finished in the same chat.

- **Acceptance**: all six lines exit 0. A helper that ran them through `eval` reported line 2 red,
  because `eval` stripped the `\b`. Run directly, it passes. The task file says so, so the next run
  is not fooled.
- **README**: the intro and the diagram said "a Windows PC". They now say Windows, Linux or macOS,
  and up to three PCs. The three decisions are stated as built, with a pointer to the invariants
  in `CLAUDE.md`. The Status paragraph no longer claims phases 2 to 4 are closed while five of
  their rows are `blocked`. SECURITY and MAINTAINING are added to the table.
- **ADRs**: all sixteen read as an outsider against the code. Ten needed edits.

## What the review found

The ADR read was the review of this wave's substance, done by a fresh-context reader before any
edit. Ten findings, all applied:

- **0009 described `e2e/run_e2e.py` as existing.** TT.8 is `todo`, and the runner has not been
  written. It is marked planned, and 0014's pointer at "the E2E suite" now points at
  `docs/TESTING.md`.
- **Missing back-links in 0002, 0003, 0004, 0005, 0012 and 0013.** Each was amended by a later
  record (0010, 0012, 0016) that its own status line did not name. Read in number order, a
  stranger met "one PC", "Windows only" and "nothing dims" before learning otherwise.
- **0005 said nothing in the app dims the screen any more.** The thermal cutoff and the night
  profile both do.
- **0010's support tiers predated the Mac.** All three launchers have now passed their shape
  checks on real hardware.
- **0015 said the action route refuses on `Sec-Fetch-Site` being present.** It refuses on any
  value other than `none`, and the ADR now says that.

Not applied, on purpose:

- The real LAN addresses in ADR 0013 and 0015 are an allowlisted, deliberate record (wave 33),
  not a leak.
- Invariant 3 in `CLAUDE.md` does not mention temperature. That is an instruction file, and
  changing it is outside a review.

## What is not proven

- **Step 4, the photo, needs the owner.** T7.3 is `blocked` on that alone.
- The README reads correctly to this reader. Whether it reads well to a stranger is the manual
  check, and nobody has done it.
- Then the flip to public, which is the owner's call, followed by the two commands in
  `docs/MAINTAINING.md`.
