# Wave 30 — four walks, and the comment that failed in its own file

**T7.9.** A design review of the seams, asked for from the chair during wave 29 in those words:
design patterns, dependency inversion, decoupling, *thinking about external contribution*.
`docs/DESIGN-REVIEW.md`, three findings filed as T10.1–T10.3, and **no code changed**.

## What ran

**T7.9**, on `wave/30-seams-review`, cut with `make wave-start` immediately after wave 29 merged.

The acceptance is five commands and they pass; `make check` is green. Nothing in `server/`,
`web/` or `android/` was touched, which is the task's own instruction — a review that also
rewrites is a review nobody can check.

## The method is the finding

Four **contributor walks**, each traced file by file: *add a theme, add an action, add a market,
add a second weather provider.* Reading the four layers explained the findings afterwards; it
produced none of them.

| A contributor wants to… | Files | Verdict |
|---|---|---|
| Add a theme | a directory + 2 lines | good — `host.js` is a registry |
| Add an action | 4 files, 3 of them deliberate | ADR 0015's defence in depth; nothing checks the lists agree |
| Add a market | a provider module + **4 scattered places in `server.py`** | the finding |
| Add a second weather provider | `App.weather()`, by editing it | **no seam at all** |

The asymmetry is one nobody would have described from memory, and it is exactly backwards from
where the effort went: `web/` has a registry, `android/` has its decisions in plain testable
classes, `server/actions.py` has a catalogue table every reader consults — and **the providers,
which are the thing a contributor is most likely to touch, have none of it.**

## The payload question got a definite answer

T7.9 required one rather than a shrug: is the comment in `DataPayload.merge` the best that can be
done?

**No, and the evidence is the comment itself.** It has failed in the file it is written in —
`night` in T6.4, then `actions` in T8.2 with the warning about the first sitting directly above
the line that dropped the second. A comment that has been read *after* the failure it describes,
twice, has produced the strongest evidence available about its own adequacy.

The shape exists in four places — `mock.js`, the server's assembly, `merge`, and the Android
test's own string literal — and nothing compares any of them. One fixture **generated by the
server** plus one assertion per layer closes the class without a schema library and without a
build step, which is what the standard-library rule leaves available. Filed as T10.1.

## A 97-case self-test that nothing runs

`server/verify_login_scope.py` carries 97 self-test cases covering the autostart parsers for all
three operating systems from fixtures — the only way macOS is checkable from this desk.
`lint-selftests` discovers self-tests with a glob over `scripts/*.py`.

They pass today. Nothing would say so if they stopped.

This is **TT.12's exact subject surviving the wave written to end it**: a self-test with no
runner, missed because the fix was a glob over one directory and the repository has checkable
code in two. Wave 25's note recorded the gap in prose. Prose did not hold — which is now the
second distinct place in this repository where that sentence has had to be written, after
`make wave-start`.

Filed as T10.3, the smallest task in the repo, and recommended first.

## What is not proven

- **The review's own manual check is unrun**, and it is the one that matters: hand the document
  and `CONTRIBUTING.md` to somebody who has never seen this project and ask where a second
  weather provider goes. The walks were done by the reader whose instincts are least
  informative — the one who has read everything.
- **The four layers were not read evenly.** The walks pulled almost all the attention into
  `server/` and the `web/`↔`android/` seam; `format.js` at 1,068 lines and the six browser checks
  were read for shape rather than adversarially.
- **No finding was verified by breaking something.** F1 rests on two bugs in the record rather
  than on a fresh reproduction. T10.1's acceptance is where that gets proved.
