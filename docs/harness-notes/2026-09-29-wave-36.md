# Wave 36 — opening the repository, as far as a private one can be opened

Before it, the history was made single-identity: 12 commits from the Mac carried the owner's work
email, and the owner asked for everything in this repository to be under the personal one.

## What ran

- **The identity rewrite, before anything else.** Branch protection blocks force-pushes, so the
  order mattered. `main` was rewritten with `git filter-branch --env-filter`, touching the 12
  commits' author and committer and nothing else. It was proved identical (181 commits before and
  after, empty tree diff, zero work-email lines) and force-pushed with a lease pinned to the old
  head. The first push died on HTTP 400 and a larger `http.postBuffer` fixed it. The three merged
  branches still holding the old commits were deleted, and the repo-local `user.email` was set.
- **T7.7**, on `wave/36-opening-the-repo`:
  - `CODE_OF_CONDUCT.md`: Contributor Covenant 2.1, fetched from upstream rather than recalled,
    with the contact filled in.
  - `SECURITY.md`, `CODEOWNERS`, a device-report issue form, and a chooser that sends questions to
    Discussions.
  - A scope section at the top of `CONTRIBUTING.md`, and every setting written into
    `docs/MAINTAINING.md` as a command.
  - Applied with `gh`: labels, Discussions, and three good-first-issues taken from real backlog
    (#49, #50, #51).

## What the review found

Four findings, all applied:

- **"The four fields the bug template asks for" was wrong.** The template has five fields, three
  of them required. The sentence no longer counts.
- **SECURITY.md pointed at a button that does not exist.** Private vulnerability reporting answers
  404 on a private repository, like branch protection. The enabling command is in MAINTAINING.md
  as the second step after the flip.
- **A second `good-first-issue` label**, next to GitHub's own `good first issue`, which is the one
  its newcomer search surfaces. The issues moved to the default label and the twin was deleted.
- **"The three invariants in the README"**: the README calls them design decisions, and the
  invariants are stated in `CLAUDE.md`. CONTRIBUTING says both now.

## What is not proven

- **Branch protection and private vulnerability reporting are not applied.** Both answer 403/404
  while the repository is private on GitHub Free. T7.7 stays `blocked` on the flip with five of
  its seven lines passing, and the two commands are ready.
- **The original work-email commits survive in `refs/pull/46..48/head`** on GitHub. Git cannot
  delete those refs; only GitHub Support can purge them. They become public with the repository.
- The issue forms were checked as YAML by the reviewer, not rendered by GitHub.

## Cost

Five prompts, including the three answers to the setup questions. Tokens were not measured.
