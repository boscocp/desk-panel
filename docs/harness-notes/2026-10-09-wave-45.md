# Wave 45 — The Mac's volume rides the stream

It began as a support question, not a wave. A permission prompt appeared at login and the owner
declined it, thinking it was something else. The check found the Application Firewall already
allowing the agent's python, the phone getting 200 on `/ping`, and python3.14 already allowed
under System Audio Recording. Nothing was broken. Then the owner asked for what wave 43 and wave
44 had both left as "next": the bar should follow the Mac's slider the way it does on Windows and
CachyOS.

## What ran

**T8.8** on `wave/45-mac-volume-stream`, PR #74:
- The Swift helper reads the default output's `VirtualMainVolume` and writes `v=` on stderr,
  once on starting and on each change. It uses property listeners, one on the volume and one on
  the default output, and does not poll.
- `reports_volume("darwin")` is True. That is the whole Python change. Nothing changed on the
  phone.
- ADR 0021 gained the amendment, and `SERVER-SETUP.md` says to rebuild an old helper.

Measured on this Mac (macOS 26.5):
- **The helper alone.** It printed `v=100` on starting, then `v=30`, `v=55`, `v=80` and
  `v=100` as `osascript` set each level. `osascript` read back the same numbers.
- **Through the agent.** `/spectrum` carried `v=100 → 40 → 70 → 25 → 100`, and `/quotes`
  agreed.
- **After the review fixes.** The final build sent `v=100 v=60 v=100`.

Test results: the server suite (650 tests) and the web suite (176) are green. Android was
untouched. This Mac has no Docker, so CI runs `./gradlew test`.

## What the review found

One fresh-context agent reviewed the diff read-only. It compiled the helper, ran the suite, and
probed `VirtualMainVolume` on this Mac with a binary of its own. It found no correctness bug.

| Severity | Finding | What happened |
|---|---|---|
| Low | The ADR said "an old helper is harmless". With `on_volume` now wired, an old helper keeps the phone's last set, and a new stream opens on it. | Reworded: stale for up to 20 s, until `/quotes` corrects it. |
| Low | The T8.6 bullet "macOS and Linux are unchanged" was marked superseded for Linux only. | Marked for macOS too. |
| Nit | The `Spectrum` docstring still named only the Windows helper. | Fixed. |
| Info | The return value of the default-output listener was ignored. | Now checked, with a line to the log if it fails. |
| Info | `VirtualMainVolume` is documented for the `AudioHardwareService*` API, deprecated since 10.11, not for `AudioObject*`. | Written into the ADR as a measured, undocumented path. If a later macOS drops it, the bar falls back to `/quotes`. |
| Test | Five Swift mutations survived the source-grep tests. | Pins added for the output scope and for which address the system listener watches. Both were sabotaged and went red. Three remain: deleting the initial read, deleting `output = device`, and `* 10`. Only a run on a Mac catches those. |

## Where the rework went

- **`make check` is red on main, not on this branch.** `lint-commits` reads the last 30
  subjects, and `d5c4e95 Remove panel image from README` went in from the GitHub web editor in
  the wrong shape. Every target after it was run one by one. Rewriting main is not this wave's
  to do. It ages out after 30 commits.
- **The first test for the default-output listener passed under its own sabotage**, because the
  regex also matched the read call two functions up. It is now anchored on
  `AddPropertyListenerBlock(`. A guard that matches the label rather than the call is the
  repository's recurring failure (T10.4).
- **No time was spent on the declined permission.** Reading the firewall app list and the
  server log first answered it in two commands.

## What is not proven

- **The bar on the Redmi.** The server side was measured, but nobody watched the phone. The APK
  takes the line (wave 43), so it should move. That is reasoned, not seen.
- **A change of output device.** The listener is in place and its registration is checked, but
  no output was switched during the run.
- **Fractional levels.** The volume keys step in sixteenths. If AppleScript rounds differently
  from `rounded()`, the stream and `/quotes` differ by 1 until the next read.
- **Any macOS other than 26.5**, given that the selector's path is undocumented.
